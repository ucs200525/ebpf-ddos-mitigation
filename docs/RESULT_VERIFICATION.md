# Result verification

Generated by `scripts/verify_results.py`. Every number below is quoted in the paper (`other/deliverables/build/paper_content.py`), the report (`report_content.py`) or the slides (`build_slides.py`). The script recomputes it from the saved result file, rounds it as the text does, and checks that the text quotes it. **Status OK** means the value, the rounding and the quotation all agree. Timing claims (source `bench`) depend on machine load; they pass when a rerun is within 50% of the quoted value, and the table shows this run's value. A quotation check only confirms that the number appears in the document, not in which sentence.
